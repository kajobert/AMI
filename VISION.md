# Vision

AMI — Artificial Mind Full Intelligence — is intended to become a modular, auditable machine-mind platform whose cognition, memory, tools, protocols and self-improvement mechanisms are owned by the AMI architecture rather than by any single external model provider.

The project is being built in public where safe. Historical material is mined through archaeology, reviewed, and then promoted into current design or implementation only when supported by evidence.

Sophia is the future autonomous entity intended to run on AMI. AMI is the reusable platform; Sophia is one entity built from it.
